# SE-Git-hw

## CINS 5318 - Software Engineering
### Assignment #1: Version Control Using GitHub

This repository was created to demonstrate the use of Git and GitHub for version control and collaborative software development.

## Project Files

### hello.py
A simple Python program originally created to print a Hello World message. This file was later used to demonstrate and resolve a merge conflict.

### apple.py
A Python program developed on the feature-1 branch that prints "I eat apple".

## Git and GitHub Activities

This project demonstrates:

- Creating and cloning a GitHub repository
- Creating and pushing commits
- Creating and working with branches
- Developing a feature on the feature-1 branch
- Creating and reviewing pull requests
- Merging a pull request into the main branch
- Creating and resolving a merge conflict
- Creating, assigning, managing, and closing GitHub Issues

## Branches

### main
The primary branch containing the completed project.

### feature-1
Created to develop the apple.py feature. The feature was reviewed through a pull request and merged into main.

### conflict-demo
Created to demonstrate a Git merge conflict.

## Pull Request and Collaboration

A pull request was created to merge feature-1 into main. A classmate reviewed the changes, provided feedback, and approved the pull request before it was merged.

## Merge Conflict Resolution

A merge conflict was intentionally created by modifying the same line in hello.py differently on the main and conflict-demo branches. Git detected the conflict and displayed conflict markers. The conflict was manually resolved by editing hello.py, removing the conflict markers, saving the final version, and committing the resolution.

## GitHub Issues

GitHub Issues are used in this project to track documentation and project review tasks. Issues are assigned to project participants and closed after the related tasks are completed.
